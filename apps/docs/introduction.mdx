# InvoicePilot AI — Documentation

InvoicePilot AI est une **solution compatible** (pas une plateforme agréée).  
Elle orchestre le parcours :

```
Sources → Analyse IA → Clients → Émission PA / Réception PA → E-reporting
```

| Couche | Rôle |
|--------|------|
| **App SaaS** | UI métier (Mes sources, Mon analyse IA, Mon émission PA…) |
| **API `/api/v1`** | Même pipeline pour éditeurs / ERP (sandbox ou live) |
| **PA** | Dépôt légal réel — InvoicePilot prépare, la PA transmet |

## Services locaux

| Service | Commande | URL |
|---------|----------|-----|
| App + sandbox API | `npm run dev` | [http://localhost:8081](http://localhost:8081) · API […/api/v1/health](http://localhost:8081/api/v1/health) |
| Docs Mintlify | `npm run docs:dev` | [http://localhost:3004](http://localhost:3004) |

<Info>
  La **sandbox tourne déjà sur votre PC** avec l’app : clé `Bearer ip_sandbox_demo`.  
  Le **LLM** (Ollama) est prévu pour le **VPS** (`docker-compose`) — en local, l’analyse utilise l’heuristique sauf `LLM_EXTRACT_ENABLED=true`.
</Info>
