|--------|--------|

## Clés live (tenant)

Depuis **Paramètres → Clés API** : préfixe `ip_live_…` liée à l’`organizationId`.  
Scopes / quotas selon le plan Stripe.

## Sécurité

- Ne committez jamais une clé live.
- Webhooks HTTPS uniquement.
- L’auth API ne remplace pas le contrat avec votre PA.
